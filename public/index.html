01

El retoThe challenge

El día a día dependía de tareas manuales y de conocimiento no documentado. Los puntos de dolor eran claros:Daily operations relied on manual tasks and undocumented knowledge. The pain points were clear:

  • Procesos y documentos repetitivos tratados a mano, con riesgo de error humano.Repetitive processes and documents handled by hand, prone to human error.
  • Cuentas de correo Gmail compartidas chocando con límites de cuota y de conexión simultánea.Shared Gmail accounts hitting quota and simultaneous-connection limits.
  • Sin una estrategia de backup y recuperación probada ante fallo de servidor o pérdida de datos.No tested backup and recovery strategy against server failure or data loss.
  • Entorno multiusuario Windows Server vía RDP sin visibilidad de rendimiento ni de consumo de recursos.Multi-user Windows Server over RDP with no visibility into performance or resource usage.
  • Incidencias de red, DNS e ISP difíciles de diagnosticar sin herramientas ni procedimientos.Network, DNS and ISP incidents hard to diagnose without tooling or procedures.

01

El retoThe challenge

  • Seguridad: el login del profesional existía pero no se aplicaba, y varias rutas de administración no exigían autenticación.Security: the practitioner login existed but wasn't enforced, and several admin routes required no authentication.
  • Datos: una tabla que la app necesitaba no se creaba en código, lo que rompía el portal de clientes en una instalación limpia.Data: a table the app relied on was never created in code, which broke the client portal on a clean install.
  • Operación: sin backups fuera del servidor, sin alertas y sin documentación para reconstruir el entorno.Operations: no off-server backups, no alerts and no documentation to rebuild the environment.
  • Uso diario: la ficha de valoración del cliente vivía en un Excel con reglas de colores que solo él sabía mantener.Daily work: the client's assessment sheet lived in an Excel file with colour rules only he could maintain.
02

La soluciónThe solution

Seguridad primeroSecurity first

Autenticación obligatoria en todas las rutas de administración, sin puertos abiertos a internet y acceso de administración solo por red privada.Authentication on every admin route, no ports open to the internet, and admin access only over a private network.

Arquitectura sencilla de mantenerEasy-to-maintain architecture

Una VM con Docker Compose para la app y PostgreSQL gestionado para los datos, en la UE. La VM es desechable; los datos, no.One VM running Docker Compose for the app and managed PostgreSQL for the data, in the EU. The VM is disposable; the data isn't.

Protección de datosData protection

Conexión cifrada y verificada a la base de datos y backups diarios cifrados en otra ubicación. El servidor solo puede escribir las copias —no leerlas ni borrarlas— y quedan bloqueadas contra borrado 30 días.Encrypted, verified database connection and daily encrypted backups in a separate location. The server can only write backups — not read or delete them — and they're locked against deletion for 30 days.

Herramienta configurableConfigurable tool

La valoración en Excel pasó a la app como un catálogo que el propio cliente edita: pruebas, rangos normales, colores y simetría izquierda/derecha. Sin depender de un programador.The Excel assessment moved into the app as a catalogue the client edits himself: tests, normal ranges, colours and left/right symmetry. No developer needed.

  • Staging en AWS probado de principio a fin: app tras Cloudflare Access, base de datos con TLS verificado, backup cifrado a S3, prueba de restauración y de reinicio superadas.AWS staging tested end to end: app behind Cloudflare Access, database with verified TLS, encrypted backup to S3, restore and reboot drills passed.
  • Alertas por email si falla un backup, la app deja de responder, el disco se llena o el servidor cae.Email alerts if a backup fails, the app stops responding, the disk fills up or the server goes down.
  • Actualizaciones de seguridad automáticas, despliegue con un comando y vuelta atrás inmediata.Automatic security updates, one-command releases and instant rollback.
  • Documentación técnica completa (11 documentos) y runbook paso a paso para montar producción en la cuenta del cliente.Complete technical documentation (11 documents) and a step-by-step runbook to build production in the client's own account.
